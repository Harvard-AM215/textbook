Three things worth fixing in memory, because they are the usual slips:

  • Poisson and exponential are the same process seen two ways. If events arrive at constant rate λ\lambdaλ, the count in a fixed window is Poisson and the gap between consecutive events is exponential. “Number of X per Y” is a count; “time until the next X” is a waiting time.

  • A binomial count requires the number of trials nnn to be fixed before you start. If the number of trials is itself the random thing you are counting, the count is not binomial.

  • N\mathcal{N}N takes the variance, not the standard deviation, throughout this book — N(μ,σ2)\mathcal{N}(\mu, \sigma^2)N(μ,σ2). Misreading σ2=4\sigma^2 = 4σ2=4 as σ=4\sigma = 4σ=4 is the single most common error with this notation.

Geometric convention. The form above counts trials including the first success, so k≥1k \ge 1k≥1 and the mean is 1/p1/p1/p. The other common convention counts failures before it, giving k≥0k \ge 0k≥0 and mean (1−p)/p(1-p)/p(1−p)/p. Both are called geometric; state which you are using.

Probability facts used everywhere¶

Independence¶

Two random variables X,YX, YX,Y are independent iff their joint mass function (discrete) or density (continuous) factorizes:

fX,Y(x,y)=fX(x) fY(y).f_{X,Y}(x, y) = f_X(x)\, f_Y(y).fX,Y​(x,y)=fX​(x)fY​(y).
(1)

Both cases matter here: the sample in P-Set 0’s joint-pmf item is discrete, and the MLE examples in Chapter 2 include both. Independence makes the likelihood of a sample factor into a product — the starting point of MLE (Ch. 2).

Linearity of expectation¶

For any X,YX, YX,Y and constants a,ba, ba,b:

E[aX+bY]=a E[X]+b E[Y].\mathbb{E}[a X + b Y] = a\, \mathbb{E}[X] + b\, \mathbb{E}[Y].E[aX+bY]=aE[X]+bE[Y].
(2)

This holds even when XXX and YYY are dependent — a frequent source of slick arguments.

Variance arithmetic¶

Var(aX+bY)=a2Var(X)+b2Var(Y)+2ab Cov(X,Y).\mathrm{Var}(aX + bY) = a^2 \mathrm{Var}(X) + b^2 \mathrm{Var}(Y) + 2ab\, \mathrm{Cov}(X, Y).Var(aX+bY)=a2Var(X)+b2Var(Y)+2abCov(X,Y).
(3)

For IID samples (so Cov=0\mathrm{Cov} = 0Cov=0, all Var=σ2\mathrm{Var} = \sigma^2Var=σ2), the variance of the sample mean is

Var ⁣(1n∑i=1nXi)=σ2n,\mathrm{Var}\!\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{\sigma^2}{n},Var(n1​i=1∑n​Xi​)=nσ2​,
(4)

giving the famous 1/n1/\sqrt{n}1/n​ shrinkage of the standard error. This is the workhorse fact behind both Monte Carlo error analysis (Ch. 3) and the t\sqrt{t}t​ scaling of random walks (Ch. 5).

Law of large numbers (LLN)¶

For IID XiX_iXi​ with finite mean μ\muμ:

Xˉn=1n∑i=1nXi→n→∞μ.\bar X_n = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow[n \to \infty]{} \mu.Xˉn​=n1​i=1∑n​Xi​n→∞​μ.
(5)

“Sample averages converge to expectations.” Justifies estimating expectations by simulation.

Central limit theorem (CLT)¶

For IID XiX_iXi​ with mean μ\muμ and finite variance σ2\sigma^2σ2:

n (Xˉn−μ)→n→∞dN(0,σ2).\sqrt{n}\,(\bar X_n - \mu) \xrightarrow[n \to \infty]{d} \mathcal{N}(0, \sigma^2).n​(Xˉn​−μ)dn→∞​N(0,σ2).
(6)

“Sample means are approximately Gaussian, with width σ/n\sigma/\sqrt{n}σ/n​.” Underwrites confidence intervals, the diffusion limit of random walks (Ch. 5), and the lognormal model of stock prices (Ch. 6).

CLT vs. extreme value theory. The CLT describes the bulk (sample averages). Extreme value theory (Ch. 8) describes the tail — the maximum or minimum of nnn samples. They have different limiting distributions and very different scaling.

Used to derive the lognormal density (Ch. 6) from a Gaussian via Y=eXY = e^XY=eX.

A note on log⁡\loglog¶

Throughout, log⁡=ln⁡\log = \lnlog=ln (natural log). The base only matters when reporting nats vs. bits; for optimization, derivatives, etc., it is a multiplicative constant that does not change the argmax.

Conventions for code¶

Every code example in the textbook uses:

  • NumPy for arrays and random sampling (numpy.random.default_rng(seed), not the legacy global np.random.seed).

  • SciPy for distributions (scipy.stats) and optimization (scipy.optimize).

  • Matplotlib for plots.

  • A passed-in rng argument for any function that consumes randomness — never module-level seeding. This matches the style we expect from student projects.

import numpy as np

rng = np.random.default_rng(seed=42)
samples = rng.binomial(n=10, p=0.3, size=1000)
